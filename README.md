# Landing de Asygna

Landing pública de **Asygna**, plataforma SaaS para planificación de turnos, reemplazos, validación de horas y gestión financiera operacional.

## Estructura

- `index.html`: estructura y contenido.
- `assets/css/style.css`: estilos y responsive.
- `assets/js/main.js`: navegación, animaciones y formulario.
- `assets/favicon/`: favicon e iconos para dispositivos.
- `assets/images/og-image.png`: imagen para WhatsApp, LinkedIn y redes sociales.
- `site.webmanifest`: instalación y apariencia en dispositivos.
- `robots.txt` y `sitemap.xml`: indexación.

## Publicación

Sube todos los archivos y carpetas conservando la estructura. El archivo de entrada debe ser `index.html`.

## Formulario

El formulario conserva su integración con Web3Forms. Revisa la clave de acceso antes de publicar el repositorio como público.

## Dominio

Los metadatos SEO usan `https://asygna.cl/`. Cambia esa URL en `index.html`, `robots.txt` y `sitemap.xml` si el dominio final es diferente.

## Versión V8

Incluye correcciones específicas para Safari/iPhone: separación de texto y panel, títulos sin palabras pegadas, escenas compactas y listas completas.
